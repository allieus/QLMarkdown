# 회고 (Retrospectives)

이슈 해결 후 필수로 수행하는 회고의 누적 산출물. **append 전용 로그가 아니라**, 매 회고마다 전체를 재검토·정리하여 일관된 고품질 문서로 유지한다.

## 운영 원칙

1. 이슈 해결 → 즉시 회고 → 본 문서 갱신 (이슈에 회고 요약 댓글도 남김)
2. 갱신 시 전체 문서를 읽고: 중복 병합, 낡은 내용 삭제/수정, 교훈은 일반화하여 아래 섹션에 배치
3. 새 작업 시작 전 본 문서를 먼저 읽는다
